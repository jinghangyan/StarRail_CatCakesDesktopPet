📡 联机教程

😸 我加入朋友的服务器
🛠 我要自己建服务器
  1. 找服主要两样东西
    Project URL（https://xxxx.supabase.co）和 Publishable key（sb_publishable_ 开头）。
  2. 填进猫猫糕
    右键猫猫糕 → 登录 / 服务器，填入 URL 和 key。
  3. 注册账号
    在同一个窗口填邮箱密码点「注册」，然后告诉服主你的用户名，互相加好友就能互戳了。
💡 成员不需要注册 Supabase、不需要碰任何服务器设置，拿 URL 和 key 就能玩。
  1. 注册并创建项目
    打开 supabase.com，注册账号 → New Project， 区域建议选 Singapore 或 Tokyo（延迟低），免费套餐即可。
  2. 执行建表脚本（仅这一次）
    项目里点左侧 SQL Editor → New query，把下方脚本全部粘贴进去 → Run。 
    加载中…
  3. 拿到两个密钥
    打开项目主页，项目名下方的 Copy 按钮（或顶部 Connect 按钮）点开， 里面就有 Project URL（https://xxxx.supabase.co）和 Publishable key（sb_publishable_ 开头）。
  4. （可选）关闭邮箱验证
    左侧 Authentication → Sign In / Providers → 关闭 Confirm email， 朋友注册后立即可用。
  5. 自己登录 + 把密钥发给朋友
    右键猫猫糕 → 登录 / 服务器 填入 URL 和 key 注册； 再把这两个值发给朋友，让他们走左边的「加入服务器」流程。
💡 URL 和 Publishable key 是公开密钥，可以放心发给朋友； 安全性由数据库规则（RLS）保证，建表脚本里已经配好了。
